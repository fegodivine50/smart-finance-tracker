# Glassmorphism Finance Tracker

A sleek, lightweight single-page web application built with HTML, custom CSS, and Vanilla JavaScript. It features a modern frosted-glass (glassmorphism) interface and real-time balance tracking for personal income and expenses.

## Features

* **Modern Glassmorphism UI:** Built using CSS variables, blur filters (`backdrop-filter`), and sleek typography (Inter).
* **Real-time Calculations:** Dynamically updates total balance, income, and expense summaries.
* **Color-coded Accents:** Instant visual distinction between income (green) and expense (red) entries.
* **Interactive Elements:** Smooth hover states, custom thin scrollbars, and functional item deletion.
* **Zero Dependencies:** Pure HTML, CSS, and Vanilla JavaScript—no external frameworks or libraries required.

## Tech Stack

* **HTML5:** Semantic layout structure.
* **CSS3:** Custom styling, CSS variables, Flexbox, and glassmorphism styling.
* **JavaScript (ES6+):** Dynamic DOM manipulation and array methods (`.reduce()`, `.filter()`).
